Longleg Frog

A pond frog on stilt legs with a sticky tongue. Every frame is drawn from one pixel rig into a 72×48 cell with a 16-colour palette, so new moves are poses, not repaints.

Sprite sheet

One row per animation, one 72×48 cell per frame, in the order listed above. The pivot sits at pixel (24, 45), on the ground between the feet. The JSON atlas beside it carries frame durations, loop flags, walk speed and the tongue hitboxes.

Files
